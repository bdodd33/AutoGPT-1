# 08 — Tools & Tech Stack

Everything you need, with free/cheap options. Total baseline ≈ **$30–50/month**;
sprint mode (with ad spend) ≈ **$650–1,550/month**.

| Job | Tool options | Cost | Notes |
|---|---|---|---|

| **Site builder** | WordPress + GeneratePress/Astra, Webflow, Carrd, Framer, 10Web | $0–25/mo | Use the included template to start free |
| **Hosting** | Cloudflare Pages (free), Netlify (free), Hostinger, SiteGround | $0–15/mo | Static template hosts free |
| **Call tracking** ⭐ | CallRail, Callsling, Nimbata, CallTrackingMetrics | $0–45/mo | **Non-negotiable.** Record + forward + attribute |
| **Forms** | Native HTML → email, Formspree, Tally, Fillout | $0 | Keep to 3–4 fields |
| **GBP** | Google Business Profile | Free | Biggest local lever |
| **Local Services Ads** | Google LSA | Pay-per-lead | "Google Guaranteed" |
| **Paid search/social** | Google Ads, Meta Ads | $20–80/day | Sprint accelerant |
| **AI copywriting** | ChatGPT, Claude | $0–20/mo | Draft all site copy fast |

## Recommended lean starter stack (≈$30–50/mo + ads)
- **Domain:** Namecheap
- **Site:** WordPress + GeneratePress *or* the included static template on
  Cloudflare Pages (free)
- **Tracking:** CallRail (start on trial) ⭐
- **Leads (fast):** Google Search Ads + LSA + QR yard signs
- **Leads (durable):** GBP + service-area SEO pages
- **CRM:** Google Sheet ([schema](../templates/lead-tracker-schema.md))
- **Payments:** Stripe subscriptions
- **AI:** ChatGPT/Claude for copy

## A note on automation (scale later, not now)
Once you have 3+ assets, automate the repetitive parts: lead notifications
(Zapier/Make → SMS to the contractor), review requests (automated texts after
jobs), citation building (BrightLocal), and reporting (auto weekly recap email).
**Don't pre-build automation in month 1** — close clients first; automate the
proven workflow second.
