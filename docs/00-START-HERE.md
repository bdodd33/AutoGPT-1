# MWFaith — Build Package (Start Here)

Everything to launch **mwfaith.com**, a luxury print-on-demand Christian apparel brand, on Shopify + TikTok Shop.

## What's in this package

| File / folder | What it is |
|---|---|
| **`/mwfaith-theme`** | Complete, installable **Shopify Online Store 2.0 theme** (luxury UI, blog, community, rewards, SEO). See its `README.md`. |
| `docs/01-BRAND-STRATEGY-AND-AVATARS.md` | Brand positioning + **4 researched customer avatars** to design/market around. |
| `docs/02-PRODUCT-MARKET-RESEARCH.md` | **Best-selling T-shirt blanks, colors, fits & design trends (2026)** + MWFaith blank strategy. |
| `docs/03-PRODUCT-CATALOG-20-DESIGNS.md` | **20 Christian T-shirt designs** based on top-selling categories, grouped into 3 collections + a women's capsule. |
| `docs/mwfaith-products.csv` | **Ready-to-import Shopify product CSV** for all 20 designs (Color × Size variants, copy, tags, SEO handles). |
| `docs/04-SHOPIFY-TIKTOK-SETUP-GUIDE.md` | Step-by-step: install theme, import products, connect **POD**, **TikTok Shop**, and **Faith Rewards**. |
| `docs/05-SEO-AND-CONTENT-PLAYBOOK.md` | Technical SEO (already built in) + keyword map + **10-post blog calendar**. |

## Recommended order
1. Read **01** (avatars) and **02** (blanks) to lock positioning.
2. Skim **03** + open the **CSV** — these are your launch products.
3. Follow **04** end-to-end to go live (theme → products → TikTok → rewards → domain).
4. Use **05** to drive traffic after launch.

## The brand in one line
> **MWFaith — Wear Your Faith. Walk in Purpose.** Luxury, made-to-order Christian apparel for the modern believer.

## Quick theme install
```bash
cd mwfaith-theme && zip -r ../mwfaith-theme.zip .
# Shopify Admin → Online Store → Themes → Add theme → Upload zip → Publish
```
(Full post-install configuration is in `docs/04-...`.)
